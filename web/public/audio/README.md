# 音频目录

单词发音 MP3，前端按 `{word}.mp3` 的命名加载。

## 当前状态

**52 个词，共 890 KB**，全部已下载到本地并提交进仓库。

## 音源策略（三级降级）

`src/lib/speak.ts` 按以下顺序自动选择：

```
1. 本地音频  /audio/{word}.mp3        ← 优先，零延迟、离线可用
2. 服务端代理 /api/tts?text=xxx       ← 兜底，代理百度/有道
3. 浏览器合成 speechSynthesis         ← 最终兜底，无需网络
```

本地音频只对 `speak.ts` 里 `LOCAL_AUDIO` 清单中的词生效——
避免每次都先 404 探测一次。

## 为什么把音频落到本地

- **不依赖第三方接口**：百度/有道是网页内部接口，随时可能改或封
- **零延迟**：不用等服务端转发
- **离线可用**：PWA 或弱网场景也能听

服务端代理只用于「清单外的新词」和「本地文件损坏」的兜底。

## 怎么新增音频

```bash
cd web
node scripts/gen-audio.mjs --dry-run   # 看会生成哪些（按图卡文件名推导）
node scripts/gen-audio.mjs             # 下载缺失的，并自动更新 speak.ts 清单
node scripts/gen-audio.mjs --force     # 全部重新下载
```

脚本会先从图卡文件名反推词表，所以**加图卡就等于加音频**。

## 音源说明

| 来源 | 语速可调 | 说明 |
| --- | --- | --- |
| 百度翻译 `gettts` | ✅ spd 1-5 | 主音源，语速跟随前端 rate |
| 有道词典 `dictvoice` | ❌ | 百度失败时兜底，音质稳定 |

**合规提醒**：这两个都是网页内部接口，不是公开 API。
用户协议可能禁止程序化调用，商用前建议评估风险，
或替换成有明确授权的服务（Azure 语音有 100 万字符/月免费额度）。

替换方式很简单：改 `src/app/api/tts/route.ts` 里的 `fetchBaidu` / `fetchYoudao`，
前端一行不用动。
