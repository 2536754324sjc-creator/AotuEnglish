# Working-composition study notice

The two PNGs beside this notice are original teaching illustrations made for UI Done, using synthetic workshop sessions and bookings. They are not screenshots of a private project, results from the old/new Skill trial, or designs approved by that project's user. They compare the same content and ordinary control responsibilities in opening and populated editing states. They demonstrate neither runtime motion nor a production save.

The illustrations are covered by the UI Done project's MIT license. Rendered third-party components remain attributable to React / React DOM (Meta and contributors, MIT), Ant Design (Ant UED and contributors, MIT), and Ant Design Icons (Ant UED and contributors, MIT). Official sources: <https://react.dev/>, <https://ant.design/>, <https://github.com/ant-design/ant-design-icons>.

Letterforms are rendered from the project's existing, unmodified Outfit and Fraunces font files (SIL Open Font License 1.1); no font software is embedded in these PNGs. Official sources and licenses: <https://github.com/google/fonts/tree/main/ofl/outfit>, <https://github.com/google/fonts/tree/main/ofl/fraunces>. These files were already recorded in the project's font notices; the study introduces no new font download or external imagery.

The separated and integrated treatments are didactic proposals, not a universal aesthetic ranking. Both keep rectangular areas, repeated records and mature controls. Inspect actual proportions, icon/text combinations, grouping and ordinary working states rather than interpreting the example as “remove containers.”
